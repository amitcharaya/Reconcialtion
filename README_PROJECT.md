# Reconciliation System

This project is a Django-based reconciliation platform for ATM, RGCS, and IMPS transactions. It supports datewise uploads of CBS, Switch, and NDPG files, reconciliation by transaction date, dashboards, dispute creation for unmatched financial exposure, and Excel report downloads.

Detailed documentation is available at:

```text
docs/PROJECT_DOCUMENTATION.md
```

Start the server with:

```bash
python manage.py runserver
```
